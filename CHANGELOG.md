## [0.1.0] - 2026-09-01

### Added

- Installable Python package with a `quakeimagery` application command.
- Streamlit interface for USGS earthquake queries and GeoTIFF overlays.
- Standalone Leaflet map using the live USGS M4.5+ feed.
- Accurate Natural Earth README map preview with magnitude and UTC date labels.
- Automated linting, tests, repository validation, packaging checks, and tagged releases.
- Community health, citation, security, and contribution documentation.
