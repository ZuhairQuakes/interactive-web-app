# Support

Use [GitHub Discussions](https://github.com/ZuhairQuakes/interactive-web-app/discussions)
for usage questions and ideas. Use the
[issue tracker](https://github.com/ZuhairQuakes/interactive-web-app/issues) for
reproducible defects and scoped feature requests.

QuakeImagery is maintained on a best-effort basis. It is an exploratory
visualisation tool and is not an operational earthquake warning or official
hazard-assessment service.
